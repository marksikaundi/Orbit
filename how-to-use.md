# How to use Orbit

```bash
zig build run
```

## Workspaces (Phase 4)

1. Arrange tabs/splits and open shells in the project directories you want.
2. **Ctrl+Shift+S** — save as a named workspace (e.g. `Backend`).
3. **Ctrl+Shift+O** — open the picker; Enter loads, Del deletes, Esc closes.

Files live in `~/.config/orbit/workspaces/<name>.toml`.
